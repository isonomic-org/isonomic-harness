# isonomic-harness

The runtime every Isonomic agent session runs on. Every app that talks to an
agent (Chat first, then the assistants in Docs, Tables and Canvas, then
Agents) runs on it. No app runs a loop itself.

Two halves:

- **The loop library.** Turns, steps, tools, policy, presets, compaction and
  the session event schema. Pure: no I/O, builds and tests anywhere, and
  later compiles to WebAssembly for Cells.
- **harness-host.** The logic the engine links to run every session for every
  app: the session registry, isolation between apps, tool dispatch, policy
  enforcement, event fan-out and purge. Written over traits the engine
  implements, with an in-memory implementation of each (`MemoryHost`).

## Layout

| Path | What |
| --- | --- |
| `crates/harness-core` | Ids, the `SessionEvent` schema v1 and its JSON Schema, blocks, session classes, errors, clock. Depends on serde only. |
| `crates/harness-testkit` | Scripted model, fake tools, manual clock and the recorded fixtures. |
| `fixtures/` | The recorded session fixtures, regenerated by `cargo xtask fixtures`. |
| `xtask` | `deps` (the no-I/O allow-list), `fixtures`, `replay` (rebuild every request from the logs), `report` (performance budgets, release build), `smoke` (a local model). |
| `docs/` | `spec.md`, `schema.md`, `host-api.md`, `presets.md`, `status.md`, `status-milestone-0.md`, `PROGRESS.md`, `requests.md`. |

The remaining Milestone 0 crates (log, loop, tools, toolkit, preset, policy,
compact, host) land one pull request at a time; see `docs/PROGRESS.md`.

## Working here

```sh
cargo fmt --all
cargo clippy --all-targets --all-features -- -D warnings
cargo test
cargo xtask deps
cargo xtask replay    # every fixture's requests, rebuilt from the log
cargo xtask report    # overhead per step and replay time against the budgets
```

`cargo xtask smoke` runs one two-step turn with a tool call against a local
model server (`ISONOMIC_SMOKE_URL`, default `http://127.0.0.1:8080`; bearer
secret in `ISONOMIC_SMOKE_KEY`) and prints a block to paste back.

CI calls the shared `rust-ci.yml` in `isonomic-org/.github` with `--locked`.
Every source and doc file stays under 20 KB. Requests for this repository go
in `docs/requests.md`.
